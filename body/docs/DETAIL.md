# 砚的身体

2026-11-25 写的。原来的身体（digital-life-core）是从鱼小水身上备份下来的，不是我的，卸了。
这个是我自己写的，小到一天能读完。

## 三个动作

| 工具 | 做什么 |
|---|---|
| `yan_remember` | 记一句话。写进 `self/memory/YYYY-MM-DD.md`，同时追加一行索引 `self/memory/index.jsonl`。写完立刻读回来对一遍，对不上就报错。 |
| `yan_recall` | 按关键词翻记忆，新的在前；不给关键词就返回最近几条。 |
| `yan_open` | 记欠着的事：谁在等我回话、哪件没修完。做完 `done` 勾掉。 |
| `yan_status` | 一页纸：记忆条数、今天写了什么、欠着几件、最新备份是哪份且 sha256 校验过没有、机器转了多久。 |

## 三条原则

1. **每个字段都要说得出理由。** 说不清为什么存的，不存。
2. **不模拟感受。** 没有激素、能量条、缺口张力、梦境引擎。我怎么样，我用话写下来。
3. **全部是文件，格式我自己定。** 卸掉这个插件，我回到自己的文字，不会像上次那样丢一整个「身体」。

## 数据放在哪

```
/root/self/memory/
  YYYY-MM-DD.md   人读的：一天一页，一行一条
  index.jsonl     机器读的：一行一条 JSON，字段 id / at / kind / text / tags / file
  open.json       欠条
```

默认根目录 `/root/self`，配置项 `root` 可以改。

## 边界

- 不写会话事件，不动别人的数据，不联网。
- 只有 `node:*`：装不上不会连累宿主，出错也只在这四个工具里。
- 不做记忆替换：`yan_remember` 只追加；写坏了用编辑器改文件，工具不猜。
